# 📚 The Book Nook - Bookstore E-Commerce Website

A beautiful and elegant bookstore homepage built with React + Vite.

## 🛠️ Built With
- React
- Vite
- JavaScript
- CSS (Inline Styles)

## 📦 Components
- Navbar
- HeroSection
- Categories
- BookCards
- WhyChooseUs
- Footer

## 🚀 How to Run
```bash
npm install
npm run dev
```
